# Digital FM Receiver (SDR) on the DE1 Kit — Phase 1

An FM receiver that tunes stations entirely with digital filters on a Cyclone II EP2C20. The kit has no RF
input, so a **virtual RF source** inside the FPGA generates exactly the signal that a 12-bit, 56.25 MS/s ADC
behind an antenna would see: 3 FM stations, noise, and multipath. Phase 2 only needs to replace the virtual
source with a real ADC through the same `ADC_D[11:0]` port.

User guide for the kit, list of completed work and next steps: **`docs/HUONG_DAN_SU_DUNG_SDR.docx`**.
The audio filter from project 1 remains unchanged (README.md, `quartus/de1_fir.qpf`) and serves as a backup demo.

```
 clk_dsp 56.25 MHz (PLL 50 x 9/8)                                                     CLOCK_50
 ┌ virtual RF source ────────────┐   ┌ receiver ───────────────────────────────────┐   ┌──────────┐
 │ A  98.5 MHz  LINE IN left     │   │ NCO + digital mixer (tune KEY1/2/3)         │   │ audio_i2s│
 │ B  98.7 MHz  melody ROM       ├──►│ CIC 5 stages ÷48          1.171875 MS/s     ├──►│ WM8731   ├─► LINE OUT
 │ C 103.3 MHz  LINE IN right    │12b│ channel FIR 127/31 tap ÷4 292.97 kS/s       │CDC│ (proj. 1)│
 │ + 8 µs multipath, 4-lvl noise │   │ CORDIC FM demod → IIR de-emphasis 50 µs     │   └──────────┘
 └───────────────────────────────┘   │ audio FIR 255 tap ÷6       48.828 kS/s      │
  real ADC (phase 2) ──► ADC_D ─────►│ RSSI, AFC                                   │
                                     └──┬──────────────────────────────────────────┘
                                        └─► data snapshot ─► UART ─► tools/live_view.py, matlab/live_view.m
```

## Files

| File | Contents |
|---|---|
| `tools/sdr_params.py` | All parameters + filter design (CIC, CIC-compensating channel FIR, audio FIR, pre-/de-emphasis, noise) |
| `tools/sdr_model.py` | **Bit-exact** fixed-point model; generates ROMs/vectors, runs measurements, exports WAV, demodulates RTL-SDR files |
| `tools/live_view.py` | Real-time display (COM port / playback / demo without the kit) |
| `matlab/live_view.m` | MATLAB version of live_view |
| `rtl/sdr_top.v` | DE1 top level: 2 clock domains, keys, switches, LEDs, HEX displays, UART |
| `rtl/sdr_core.v` | The entire 56.25 MHz domain: `vsrc` + receiver |
| `rtl/vsrc*.v`, `rtl/melody_rom.v` | Virtual RF source: FM modulation + pre-emphasis, melody, xorshift noise, multipath |
| `rtl/rx_mixer.v`, `rx_cic.v`, `fir_decim.v`, `rx_fm_demod.v`, `rx_deemph.v`, `rx_rssi.v` | Receive chain |
| `rtl/rx_tuner.v`, `btn_ctrl.v` | Manual tuning / auto-scan (RSSI + AFC) |
| `rtl/snapshot_uart.v`, `uart_tx_div.v` | Captures sample blocks, sends `A5 5A` frames over UART |
| `rtl/cdc_word.v`, `rtl/pll_dsp.v` | Data transfer between the 2 clock domains, PLL |
| `rtl/*.hex` | Sine ROM, FIR coefficients (auto-generated — do not edit by hand) |
| `sim/tb_fir_decim.v`, `sim/tb_sdr_core.v` | Bit-exact verification against the Python model |
| `sim/tb_sdr_top.v` | System simulation: WM8731 codec, keys, auto-scan, UART |
| `sim/run_sim_sdr.bat` | Runs everything (`run_sim_sdr.bat quick` skips the system testbench) |
| `quartus/de1_sdr.qpf` | Quartus II 13.0 SP1 project |
| `doc/sdr_*.png`, `doc/sdr_measure.txt` | Filter responses, measurement results, GUI screenshots |
| `demo/sdr/*.wav` | Audio for each station / each scenario, generated by the bit-exact model |

## Commands

```bat
python tools\sdr_model.py design        :: generate ROMs + check RTL constants + plots
sim\run_sim_sdr.bat                      :: 3 testbenches, must print PASS
python tools\sdr_model.py measure        :: measure SINAD/CNR, adjacent channel, capture effect, multipath
python tools\sdr_model.py wav            :: demo\sdr\*.wav
python tools\live_view.py --demo         :: preview the GUI without the kit
python tools\live_view.py COM5           :: real kit (RS-232, 115200)
```

To change parameters: edit `tools/sdr_params.py` → `design` (reports an error if hand-written constants in the
RTL don't match) → `run_sim_sdr.bat` → recompile in Quartus.

If Quartus reports error 297009 or 138001 about write permission (OneDrive sets the read-only flag on folders):
run `attrib -r *.* /s /d` in the `quartus` folder.
